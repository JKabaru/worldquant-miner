## 💡 Key Insights

1. **Correlation is King**: The 0.70 threshold is strict. Use the checker BEFORE every submission.

2. **10% Exception Rule**: If your new alpha has correlation > 0.70, it can still pass if Sharpe is 10% higher than the correlated alpha.

3. **Diversification Strategies**:
   - Use different operators (ts_mean vs ts_rank vs ts_zscore)
   - Vary lookback periods significantly (5 vs 20 vs 60)
   - Mix data fields (close vs volume vs returns)
   - Apply group neutralization differently

4. **Operator Substitutions**:
   - ❌ `correlation(x,y,d)` → ✅ `ts_corr(x,y,d)`
   - ❌ `delta(x,d)` → ✅ `ts_delta(x,d)`
   - ❌ `delay(x,d)` → ✅ `ts_delay(x,d)`
   - ❌ `neutralize(x,g)` → ✅ `group_neutralize(x,g)`
